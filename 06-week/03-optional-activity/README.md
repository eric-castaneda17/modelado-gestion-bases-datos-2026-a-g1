## Reflexión: Comparación entre PostgreSQL y MySQL

En el desarrollo de este taller se trabajó con dos sistemas gestores de bases de datos relacionales muy utilizados en la actualidad: **PostgreSQL** y **MySQL**, ambos ejecutados mediante contenedores Docker. La realización de este laboratorio permitió conocer mejor el funcionamiento de cada motor y comparar sus principales características a partir de una experiencia práctica.

PostgreSQL se presenta como una base de datos más robusta y estricta en cuanto al cumplimiento de los estándares SQL. Durante el ejercicio, su uso resultó organizado y consistente, especialmente en la creación de la base de datos, la definición de la tabla y la ejecución de consultas. Esto permite entender por qué PostgreSQL es utilizado frecuentemente en aplicaciones que requieren mayor control, integridad de datos y funcionalidades avanzadas.

Por su parte, MySQL se destacó por ser más sencillo de configurar y utilizar. Los comandos fueron fáciles de ejecutar y el proceso de creación de la base de datos, inserción de datos y consultas se realizó de manera rápida. Esto demuestra por qué MySQL es muy común en aplicaciones web y proyectos donde se busca simplicidad y rapidez en el manejo de la información.

En conclusión, ambos sistemas cumplen correctamente con los requerimientos básicos de un sistema de bases de datos relacional, como la creación de tablas, la inserción de registros y la ejecución de consultas SQL. PostgreSQL ofrece mayor robustez y control, mientras que MySQL resulta más práctico y fácil de usar. El uso de Docker facilitó significativamente la implementación de ambos motores, permitiendo trabajar en entornos aislados sin afectar la configuración del sistema operativo.
